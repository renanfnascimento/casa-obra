# Obra da casa — Aparecida de Goiânia

Painel da obra: planta editável, maquete 3D, orçamento, simulador de aporte,
lista de compras e achados de material.

em 4 módulos, cada um habitável ao terminar.

App local, sem servidor: os dados que você digita ficam no navegador.
